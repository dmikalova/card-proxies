# Card backs

A run prints the proxy card backs in this directory, `spellbook-claude.png`
and `atlas-claude.png`. They are the official backs with a PROXY logo in place
of the Sorcery logo. Git tracks these two files.

To print other backs, replace these files. Each back can be a `.png`, `.jpg`
or `.jpeg`. A landscape atlas back turns to portrait to match the card images.

Keep the official backs here as `spellbook` and `atlas`. They are the source
of the proxy backs. Git ignores them.
